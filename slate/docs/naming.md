# Naming — vetted shortlist & verdicts

*July 2026. Companion to [market-strategy.md](market-strategy.md).*

## The uncomfortable conclusion first

**Coin a word. Don't use a real one.** Every evocative English word in this
category is already taken — usually by either a funded fintech (trademark risk
in your exact class) or a direct competitor (search-invisibility). This isn't
bad luck; it's a saturated category. The apps that won here all used *coined*
names: Splitwise, Venmo, Zelle, Revolut, Tricount. Real dictionary words get you
no exact-match `.com`, no defensible trademark, and a page-two Google ranking on
day one.

**Kittysplit, Tab, Billzer, Spliteroo, SplitMyExpenses, KttiPay** — the field is

thesis: compete on the **couples/household wallet-linking wedge**, not on being
"another clean splitter."

## Recommendation: coin around the wedge

Best story you have is *"finally handles couples & families in a group."* Coin a
short, warm, brandable word that hints at *together / even / settled* — not at
*split* (catastrophically saturated: Splitwise, Splid, Splittr, Spllito,
SplitSnap, SplitEven, SplitterUp, Spliteroo, SplitMyExpenses…).

Starter set to run through the checklist below (I could not auto-verify domains —
DNS/RDAP are blocked in my sandbox — so treat these as *unvetted seeds*, not
cleared names):

- **Evenly / Evvy** — "we're even." Warm, short. (Some collisions likely — check.)
- **Tabbl / Tabbi** — a "tab," coined spelling for a clean `.com` shot.
- **Sortd** — British "it's sorted" = settled/done. Coined, ownable.
- **Poola / Poolo** — you pool the money. Distinctive, no "split."
- **Settl / Settlo** — the moment of settling up.
- **Kitro** — echoes "kitty" (shared pot) without colliding with Kittysplit.

Pick for feel, then let the checklist eliminate. Don't fall in love before step 3.

## The 3-check vetting process (5 min per name)

Run these yourself in this order — cheapest disqualifier first:

1. **App Store + Google Play search.** Any existing *finance/expense* app with
   the name (or a near-homophone)? If yes → drop it. This is the fastest kill.
2. **Domain.** Is the exact `.com` (or a clean `brand.app` / `getX.com`)
   gettable at a normal price? Type it at any registrar (Namecheap, Porkbow,
   Cloudflare Registrar). A $5k premium listing = effectively taken.
3. **Trademark.** Search **USPTO TESS** (tmsearch.uspto.gov) in classes **9**
   (software) and **36** (financial services). A live mark by a funded fintech
   in those classes = walk away. No hit = good enough to start; you can file
   your own later (~$250–350/class, DIY).

If a name passes all three, grab the domain + both store listings *the same day*
— brandable names get taken fast.
